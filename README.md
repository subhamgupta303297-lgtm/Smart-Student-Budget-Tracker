# 🎓 Smart Student Budget & Expense Analyzer

A lightweight, console-based Java application designed to help college students track daily expenses, monitor budget thresholds, and prevent overspending with proactive warnings.

## 📌 Problem Statement
Managing pocket money and daily hostel/college expenses (mess, commute, books) is challenging for first-year students. Without continuous feedback, budgets often get exhausted before month-end.

## 🚀 Key Features
- **Categorized Expense Logging:** Track spendings across Food, Study, Travel, and Personal needs.
- **Automated Threshold Warnings:** Triggers a dynamic alert at 80% budget consumption and flags critical overruns.
- **Summary Analytics:** Real-time calculation of total spent, remaining balance, and historical logs.
- **Zero Dependencies:** Pure Core Java implementation utilizing OOP principles and ArrayList structures.

## 🛠️ Tech Stack
- **Language:** Java (JDK 17+)
- **Concepts:** Object-Oriented Programming (Classes & Encapsulation), Collections Framework (`ArrayList`), Scanner I/O.
